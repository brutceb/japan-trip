# Japan itinerary

Public GitHub Pages site for the October 2026 trip.

Repo: https://github.com/brutceb/japan-trip  
Site (after Pages is turned on): https://brutceb.github.io/japan-trip/

## Turn on Pages

1. Open **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Save

The live URL appears at the top of that page after the first build.

Click a day row to expand the timed plan, options, food, and logistics.
Edit `itinerary.js` to change the trip.
